# Day 2: Linear regression

- `student_scores_lab.py`: predicts `exam_score` using `study_hours`, `attendance`, and `assignments_completed`, with a 25% holdout and MAE.
- `linear_regression_notes.py`: lesson snippet covering fitting, coefficients, intercept, predictions, and MAE. It needs `X` and `y` defined before execution.

The original `student_scores.csv` was not present in the practice folders and is not included. To run the score lab, provide a numeric CSV with the four column names above in the current working directory. No replacement data has been invented for this upload.
