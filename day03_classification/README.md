# Day 3: Classification

Three self-contained exercises using small hand-written datasets:

- `purchase_probability.py`: purchase classification, `predict_proba`, accuracy, and a confusion matrix.
- `student_pass_classification.py`: pass/fail classification, precision, recall, F1, and a classification report.
- `employee_promotion_lab.py`: promotion classification using experience, performance, and completed projects.

Run a script from the repository root, for example:

```sh
python day03_classification/employee_promotion_lab.py
```

The tiny educational samples are for understanding the workflow. High scores on them do not show readiness for real educational, employment, or customer decisions.
